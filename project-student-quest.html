Student Quest

A unified student hub for social connection, campus services, and academic needs, built from real student voices at CU Boulder.

Context
Software engineering course, University of Colorado Boulder
Team
Product lead on a team of 5
Research
20 CU Boulder students
Stack
HTML · CSS · JavaScript · FastAPI · SQL

The goal

What problem were we solving?

College students juggle academic deadlines, campus events, social plans, and services, but no single platform brings it together. Each need lives in a different app or on a flyer on a bulletin board.

Student Quest set out to fix that: one centralized hub built around three pillars (social, service, and academic) in one clean web platform.

My contribution

What did I build?

  • Originated the product concept and defined the three pillar vision: social, service, academic
  • Ran structured user research with 20 CU Boulder students to validate the concept
  • Oversaw development as product lead for a team of 5 engineers
  • Owned and built the entire front end in HTML, CSS, and JavaScript from scratch
  • Coordinated with a backend teammate to align the API structure with UI requirements
  • Translated raw feedback into feature decisions and sprint priorities

Skills gained

What did this teach me?

HTML, CSS and JavaScript · FastAPI · SQL · Project management · Front end architecture · Team leadership · User research · API integration · Product thinking
